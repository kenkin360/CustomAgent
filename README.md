# CustomAgent

Flow host contains exactly four files: `App.tsx`, `Bundle.js`, `Resource.js`, and `Function.extend.js`. Copy those four files into Flow host using the same filenames. `App.tsx` is a small `Function.extend(React.Component)` loader, following FlowerX's entry point. `Bundle.js` loads the following plain JavaScript files from this repository through `esm.sh` as classic scripts, in dependency order:

- `views/agent.html.js` — interface markup and styles
- `https://esm.sh/gh/TechStark/opencv-js/dist/opencv.js?raw` — OpenCV.js, available as `cv` after initialization
- `ImageService.js` — Flow media, camera, generation, and download operations
- `Assistant.js` — text model calls, welcome, conversation, action decisions, and replies
- `CustomAgent.js` — the App, its UI API, state, extension registration, source inspection, and rollback

Every remotely loaded file is a classic script with a top-level `var` whose name exactly matches the requested resource name. `Resource.Module` reads that name from `globalThis`; classic scripts expose top-level `var` there without an explicit assignment. Remote scripts have no top-level `import` or `export`. The host's `Bundle.js` and `Resource.js` remain ES modules because `App.tsx` imports them. `App.tsx` also exposes `App`, `Bundle`, and `Resource` to the loaded scripts.

`DrawRectangle.js` and `Upscale.js` each define a `Function.extend(Object, ...)` class and an internal singleton with a bound static `Run` method. They are preloaded through `LoadModule(source, options)`, the same entry used for later modules. It calls `Resource.Module` and retains the loaded value under `AppRuntime.Modules`; a static `Run` is callable under the same module name without constructing another instance. Assistant-authored modules use a script URL or JavaScript source with a matching top-level `var`; no base class or instance is required. The source is a separate text argument, not `arguments.code` in control JSON. Each code update should use a fresh name. `rollback` reverses only the latest module and function registration; modules that change UI must arrange their own cleanup. `Upscale` loads WebSR from `https://esm.sh/gh/sb2702/websr/dist/websr.js?raw` when first used.

`Assistant` subscribes to App messages and events, reads the App state, calls `Flow.generate.text`, and sends its answers through `CustomAgent.Reply`. The welcome message and operation results are generated by the model. The model receives up to 20 preceding messages plus the current message separately. Image generation starts only after the user chooses Generate. The UI supports multiple input lines with Shift+Enter.

The processing indicator is a temporary conversation item immediately after the current user message. The Send button becomes Stop while the assistant is working. Stop hides the indicator and discards late text model replies; already completed local actions are retained. After a local operation, the assistant receives the actual result and refreshed runtime capabilities before deciding what to do next. Missing actions can be implemented as modules using `loadModule`; modules can draw on an offscreen canvas or mount interface controls.

`Assistant` uses a Chinese system instruction adapted to these runtime APIs and sends a nonempty startup text prompt. Startup receives compiled file names and `Bundle.Config`, not source contents. The complete compiled host source is decoded and split once at App construction and then kept in memory. `readCompiledSource({file})` returns a full stored file, `readRemoteSource({name})` may fetch a remote file again, and `readInstalledSource({name})` returns the exact JavaScript supplied at installation or refetches a remotely installed file. Normal conversations require one text generation call; follow-up calls occur when an action's result needs another decision. Static UI labels are selected once from the browser language, with English fallback, while model replies follow the user's language.

The output ratio defaults to `原圖`. With a source image, generation uses its decoded pixel aspect ratio; without one, the request leaves the ratio unspecified for Flow.

Selected, captured, generated, and locally edited images record their decoded pixel dimensions and actual aspect ratio. `Assistant` receives the current image dimensions separately from the selected generation aspect ratio. Registered runtime functions may publish a `Description` for generic capability inspection; `Upscale` accepts optional `width` and `height` pixel targets and fits the full image into that canvas without distortion.
